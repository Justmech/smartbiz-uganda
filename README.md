# SmartBiz Uganda

A mobile-friendly, local-first sales, inventory, expense and profit tracker for small businesses.

## Current MVP features
- Record sales and automatically reduce stock.
- Track product costs, selling prices, stock quantities and low-stock thresholds.
- Record operating expenses.
- View daily sales and gross profit, monthly recorded expenses, stock alerts and all-time summaries.
- Search sales and inventory.
- Export CSV reports and download/restore a JSON backup.
- Responsive interface for phones and desktops.
- Uses UGX for currency display.

## Run it
Open `index.html` in a modern browser, or publish this public repository with GitHub Pages.

## Important limitations
- Data is stored in the current browser on the current device using localStorage. It does not sync between devices and can be lost if browser data is cleared. Use backups.
- This is an MVP, not audited accounting software. Net profit is calculated from recorded sales, stored product costs and entered expenses.
- No customer accounts, cloud sync, tax calculations, online checkout, or payment processing are included yet.
- The product does not currently collect payments. A separate payment provider and supported payout route must be verified before selling access or downloads.
